# TSE Admin

Vite + React + Tailwind CSS + shadcn/ui baseline setup.

## Scripts

- dev: start dev server
- build: type-check + build
- preview: preview production build

## Config

- API base URL is read from `VITE_API_URL` (defaults to `http://localhost:3000`).
- Create a `.env` file at project root to override:

```bash
echo "VITE_API_URL=http://localhost:3000" > .env
```

## Quick Start

1. Install dependencies
2. Start dev server

```bash
npm install
npm run dev
```

Then open http://localhost:5173.
